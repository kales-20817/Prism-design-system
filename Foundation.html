Foundation

The foundational design tokens, color systems, typography, spacing, and visual constants that underpin every component in the UEMS Design System.

Tokens

Design tokens are the single source of truth for storing visual design attributes such as colors, spacing, and typography scales.

Tokens
Comprehensive token documentation including naming conventions, semantic mappings, and platform-specific implementations.

Accessibility

Accessibility tokens ensure that contrast ratios, focus indicators, and motion preferences are maintained across the entire design system.

Tokens Accessibility
Guidelines for WCAG-compliant tokens covering color contrast, focus rings, reduced-motion preferences, and screen reader support.

Content

Content guidelines define the voice, tone, and writing patterns used across all UI surfaces to ensure clarity and consistency.

Content
Voice and tone framework, UX writing conventions, and content patterns for labels, messages, and microcopy.

Spacing

The spacing scale provides a consistent set of values for margins, paddings, and gaps that maintain visual rhythm throughout interfaces.

Spacing
Spacing scale definitions, density modes, and practical usage examples for building consistent layouts.

Grid

The grid system defines responsive column layouts, breakpoints, and alignment rules that structure page content across all viewport sizes.

Grid
Grid column specifications, breakpoint definitions, gutter sizes, and responsive layout patterns.

Color

The color system provides semantic palettes, theming support, and accessible color combinations for all UI elements.

Color
Primary, secondary, neutral, and semantic color palettes with light/dark theme mappings and usage guidance.

Typography

Typography defines the type scale, font families, weights, and line heights used to establish clear visual hierarchy and readability.

Typography
Type scale, font families, weight mappings, line-height ratios, and responsive typography guidelines.

Iconography

The icon system provides a consistent set of vector icons with defined sizing, stroke weights, and color application rules.

Iconography
Icon library overview, sizing conventions, stroke specifications, and implementation patterns.

Illustrations

Illustration guidelines cover the visual style, usage contexts, and theming rules for spot and full-page illustrations.

Illustrations
Illustration style guide, empty state illustrations, onboarding graphics, and theming support.

Elevation

Elevation tokens define shadow depths and layering to communicate hierarchy and interactive affordances across surfaces.

Elevation
Shadow depth scale, z-index layering system, and elevation usage patterns for cards, modals, and popovers.

Border

Border tokens specify widths, styles, and color treatments for dividers, outlines, and interactive element boundaries.

Border
Border width tokens, style variations, color mappings, and contextual usage patterns.

Radius

Border radius tokens define the curvature scale applied to containers, buttons, inputs, and other interactive elements.

Radius
Radius scale tokens, component-specific radius mappings, and pill/circle shape conventions.
