Components

Components are the reusable building blocks of the Prism design system. Use them to build consistent, accessible, and scalable Endpoint Central experiences.

Forms and inputs

Button
Triggers an action or event when clicked.
Checkbox
Allows selection of one or more options from a set.
Combobox
Combines a text input with a dropdown list for filtered selection.
Date picker
Lets users select a date or date range from a calendar.
Dropdown
Displays a list of actions or options on demand.
Filter input
Narrows data by applying filter criteria inline.
Form
Groups related inputs and manages validation and submission.
Radio button
Selects a single option from a mutually exclusive set.
Search
Provides a text input for querying and filtering content.
Select
Lets users choose a single value from a predefined list.
Slider
Allows selection of a value from a continuous range.
Split button
Combines a primary action with a dropdown of alternatives.
Switch
Toggles a setting between two states instantly.
Text area
Multi-line text input for longer content entry.
Text field
Single-line text input for short-form data entry.

Data display

Badges
Small status descriptors for counts or labels.
Cards
Contained surfaces for grouping related information.
Chip (Counter)
Compact element for displaying counts or attributes.
Code snippet
Displays formatted code with syntax highlighting.
Data table
Organizes data in sortable, filterable rows and columns.
Help text
Provides contextual guidance below form fields.
Icon
Visual symbols for actions, objects, and concepts.
Label
Identifies and describes form controls and data fields.
Link
Navigates users to another page or resource.
List
Displays a series of related items vertically.
Status indicator
Communicates the current state of a process or item.
Tag
Categorizes or labels content with removable keywords.
Tree view
Displays hierarchical data in an expandable tree structure.

Navigation

App bar
Top-level container for branding and global actions.
Breadcrumbs
Shows the user's location within a page hierarchy.
Navigation bar
Primary horizontal navigation for top-level sections.
Page header
Displays the page title, description, and actions.
Pagination
Splits content across multiple pages with navigation.
Segmented control
Switches between related views within a single context.
Sidebar
Vertical navigation panel for section-level wayfinding.
Tabs
Organizes content into selectable tabbed panels.

Messaging and feedback

Action bar
Toolbar for contextual bulk actions on selected items.
Action button
Icon-only button for frequent or floating actions.
Action list
A vertical list of interactive action items.
Alert banner
Page-level notification for important system messages.
Bottom sheet
Slides up from the bottom to reveal supplementary content.
Dialog
Focused overlay that requires a user decision.
Divider
A thin line that separates content into groups.
Drawer
A panel that slides in from the edge of the screen.
Empty state
Placeholder shown when there is no content to display.
Inline message
Contextual feedback displayed within the content flow.
Modal
An overlay window for focused tasks and confirmations.
Popover
Floating container for additional content or actions.
Progress bar
Visualizes the completion percentage of an operation.
Progress indicator
Animated spinner for indeterminate loading states.
Snackbar
Brief message that appears temporarily at the bottom.
Tooltip
Small popup that describes an element on hover or focus.

Layout and structure

Accordion
Expandable sections that show and hide content.
Autocomplete
Text input with predictive suggestions as you type.
Button group
Groups related buttons into a single connected row.
Menus
Temporary list of choices triggered by user interaction.

Images and icons

Avatar
Represents a user or entity with an image or initials.
Icon
Visual symbols used for actions, navigation, and status.
